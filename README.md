# Baste E-Bike & E-Car — Silver / Blue / Yellow Theme

React + Vite landing page using the supplied winged Baste logo and the provided e-car promotional posters.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
```

Vite writes the production site to `dist/`. The product posters are stored locally under `public/images/products/`, and the supplied logo is stored under `src/assets/baste-logo-new.png`.

## Features

- Silver, metallic blue, and logo-yellow business theme
- Responsive layout and fixed bottom navigation
- E-car poster catalog with overlay to browse all models
- Individual poster lightbox and Facebook inquiry link
- Click-to-call contact links
- Embedded Google Maps and external directions link
- Branded loading screen

Note: Dependency installation and production build were not verified in this environment because `npm install` timed out. Run the commands above locally before deploying.
